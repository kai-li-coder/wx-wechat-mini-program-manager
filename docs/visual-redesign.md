# 管理端视觉重设计说明（参考图还原版）

> 范围：登录页、埋点总览、链路事件、错误日志，以及全局布局与公共组件。
> 约束：仅调整视觉呈现，接口、状态管理、查询/分页/登录等交互逻辑保持不变。

## 1. 设计定调

参考图为「浅色 SaaS 仪表盘」：浅薰衣草画布、白色圆角卡片、亮绿色主色、蓝色数据图表、柔和阴影与填充式输入框。本次还原保留该图的核心视觉特征，同时沿用现有后台的信息结构。

| 维度 | 决策 |
| --- | --- |
| 画布 | 浅薰衣草 `#EDF1F8`，比纯白更柔和，让白色卡片形成清晰层次 |
| 表面 | 纯白 `#FFFFFF` 卡片与侧边栏 |
| 主色 | 亮绿 `#16A34A`（实底）、`#22C55E`（强调/图表），用于激活导航、主按钮与关键数值 |
| 辅助色 | 蓝色 `#4F8DF7` 用于趋势图与候选人系列；琥珀 `#F59E0B`、红色 `#EF4444` 保留为警告/失败语义 |
| 文字 | 深海军蓝 `#1E2433`，次级 `#5F6879`，辅助 `#6F7789` |
| 圆角 | 卡片 16px、按钮/输入框 10px、标签 8px、登录面板 20px、胶囊 999px |
| 阴影 | `0 6px 20px rgba(23,32,56,.05)`，悬停层级 `0 12px 32px rgba(23,32,56,.09)` |
| 字体 | 本机中文无衬线（HarmonyOS Sans SC / MiSans / PingFang SC），标题 700、正文 400/500；不引入外部字体 CDN |

### 2.1 圆角与阴影

- 卡片统一 `border-radius: 16px`，由 `$radius-md` 控制；`MetricSummary` 的 `<article>` 与 `el-card` 使用同一值。
- 按钮、输入框、下拉、日期选择器统一 `10px`（`$radius-sm`），标签与分页按钮 `8px`（`$radius-xs`）。
- 卡片阴影只保留一层柔和环境阴影，不使用重投影；表格、图表卡片共用 `$shadow-panel`，浮层（下拉、消息）使用 `$shadow-raised`，登录面板使用 `$shadow-overlay`。
- 卡片边框为 `#EFF2F8`，只承担边缘定义，不与阴影叠加出厚重感。

### 2.2 字体与间距

- 页面标题 28px/700、卡片标题 16px/700、正文 13–14px、标签 12px、微文案 10–11px。
- 数字统一 `font-variant-numeric: tabular-nums`；指标数值改用无衬线字体，仅 JSON 代码保留等宽字体，贴近参考图的圆润观感。
- 卡片内边距 20–22px，卡片间距 16px；页面左右内边距收紧至 20px（≤1280px 为 16px、≤768px 为 12px），在保持居中的同时让主体更充分地占用可用宽度。

## 3. 组件还原

### 导航

- 白色侧边栏，236px；品牌标记为绿色渐变圆角方块（10px 圆角 + 绿色投影）。
- 菜单项 40px 高、10px 圆角；激活态为整块绿色胶囊 + 白色图标文字 + `0 6px 16px rgba(22,163,74,.24)` 投影，对应参考图 Home 项。
- 折叠态保留绿色胶囊，仅显示图标。

### 顶栏

- 不再使用独立白色横条，改为 90% 画布色 + 12px 背景模糊，使顶栏融入浅色画布，贴近参考图内容区。
- 服务状态为浅绿胶囊 + 绿色状态点；头像使用浅绿底 + 绿色描边。

### 卡片与面板

- 所有卡片：白底、16px 圆角、`#EFF2F8` 边框、柔和阴影。
- 面板标题 16px/700，说明文字 11px 灰色；不再使用装饰性编号与左侧色条，保持参考图的干净标题。

### 按钮与表单

- 主按钮：绿色实底、白色文字、10px 圆角、`0 6px 16px rgba(22,163,74,.24)` 投影。
- 次按钮：白底、`#E3E8F2` 边框，悬停转浅绿底 + 绿字。
- 输入框：填充式 `#F5F7FC`，无可见描边；聚焦转白底并出现 1px 绿色边 + 4px 绿色光环。

### 指标卡

- 六张卡片均为白色 16px 圆角；主卡使用 `#F3FCF7 → #FFFFFF` 浅绿渐变高亮，数值为深绿，保留结果构成条。
- 成功/警告/失败分别使用 `#22C55E`、`#F59E0B`、`#EF4444` 的 4–6px 圆角占比条。

### 表格与分页

- 表头 `#F7F9FC`，行分隔线 `#F1F4FA`，行悬停 `#F8FAFF`；固定操作列使用不透明白底，避免透出下层内容。
- 分页激活项为绿色实底、8px 圆角。

### 登录页

- 浅色画布 + 绿色/蓝色两枚大范围模糊光晕；登录面板为 420px 白色卡片，20px 圆角、柔和深阴影。
- 品牌标记与侧边栏一致；表单使用填充式输入框，主按钮高 44px、12px 圆角。

### 图表

- 候选人趋势使用蓝色 `#4F8DF7` 折线与 18% 蓝色渐变面积；异常趋势保留失败/警告/成功语义色。
- 坐标轴标签 `#7B8394`、轴线 `#E8ECF5`、分隔线 `#EEF1F7`，提示框白底、10px 圆角、柔和阴影。

## 4. 实现要点

1. 设计令牌集中在 `src/styles/tokens.scss`；Element Plus 主题桥接与组件覆盖在 `src/styles/base.scss`。
2. **选择器优先级**：构建产物会把 Element Plus 默认 `:root` 排在项目样式之后，因此主题变量使用 `:root:root`，组件覆盖统一包在 `html {}` 作用域内，避免默认蓝色与 4px 圆角反超。
3. 表格固定列显式设置不透明背景（`td` 白、`th` 浅灰、hover 跟随行悬停色），修复横向滚动时「操作」列透出下层文字的问题。
4. 输入框的填充式样式通过覆盖 `.el-input__wrapper`、`.el-select__wrapper`、`.el-textarea__inner` 的 `background-color` 与 `box-shadow` 实现，未改动任何表单逻辑。

## 5. 响应式

| 断点 | 行为 |
| --- | --- |
| ≤1440px | 指标区 6 列 → 3 列，主卡横跨 3 列 |
| ≤1400px | 查询表单 4 列 → 2 列 |
| ≤1240px | 总览图表双栏 → 单栏 |
| ≤1024px | 侧边栏折叠为 76px 图标栏，折叠按钮隐藏 |
| ≤768px | 查询表单单列、指标 2 列、卡片内边距 16px、抽屉 92%、分页换行 |

## 6. 动效与可访问性

- 页面区块以 60ms 间隔、8px 上浮完成一次入场；`prefers-reduced-motion` 下 CSS 动效与 ECharts 入场动画均关闭。
- 正文与次级文字对比度 ≥ 4.5:1；绿色实底按钮/胶囊与白色文字为 3.3:1，达到界面组件 3:1 要求（用于 13–14px 粗体标签）；关键状态均有文字与色点双重编码。
- 焦点环统一 2px 绿色描边 + 2px 偏移。
